# Portret7997Bot

Telegram бот Надії Царенко: портрет за датою народження, 33 позиції та персональні описи.

- Позиції 21 і 30 безкоштовні.
- Платний доступ належить конкретному Telegram користувачу та одній даті народження.
- Опис позиції або весь портрет можна придбати через Telegram Stars після налаштування цін.
- Платні описи зберігаються приватно, поза цим репозиторієм.
