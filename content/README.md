# Каталог описів

`positions.json` містить усі 726 текстів. Це приватний вміст для сервера.
Не завантажуйте його у публічний репозиторій: тоді платні описи можна прочитати без покупки.

Для поточного публічного репозиторію залиште файл поза Git.
На Railway завантажте його до постійного тому як `/data/content/positions.json`.
Бот знайде його там автоматично. За потреби шлях можна встановити змінною `CATALOG_PATH`.

У приватному архіві файл уже є у цій папці, тому локальний запуск працює одразу.
Альтернатива для розгортання: приватний репозиторій із цим файлом, доданим через `git add -f`.
Самостійно публічність наявного репозиторію не змінювалася.
